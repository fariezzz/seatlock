Seatlock

Sistem reservasi tiket bioskop berbasis gRPC.

Tampilan web ini hanya perantara: setiap klik diteruskan gateway HTTP menjadi pemanggilan gRPC ke server bioskop. Status diperbarui live lewat server streaming gRPC yang diubah gateway menjadi SSE.

Klik satu kursi, lalu tekan tombol di bawah. Kursi yang sudah terpesan tidak bisa diklik.
